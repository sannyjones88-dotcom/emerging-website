## 🌟 Overview & Key Features

This platform is a comprehensive, production-ready, interactive web experience built specifically for presenting and mastering **Chapter 10: Emerging Technologies**.

### 1. All 15 Required Topics Covered in Full Depth
Every single topic features an 8-section holographic educational dossier:
- **A. What Is It?** — Plain-English definition, core purpose, and what distinguishes it from older tech.
- **B. Where Did It Come From?** — Accurate historical origins, verified dates, and pioneer inventors.
- **C. How Does It Work?** — Step-by-step visual flowchart diagram + simple everyday analogy.
- **D. Advantages** — At least 4 concrete benefits to students, society, and industry.
- **E. Disadvantages & Risks** — At least 4 challenges, security vulnerabilities, and ethical pitfalls.
- **F. Real-Life Scenarios** — 3 realistic, relatable narratives showing how everyday people use it.
- **G. Why It Matters** — Future trajectory, economic significance, and career opportunities.
- **H. Key Takeaway** — A memorable, punchy core principle to remember for college exams.

### 2. Interactive Highlights
- **15-Question Interactive Knowledge Quiz:** Instant answer evaluation, color-coded feedback, in-depth explanations for every choice, and a dynamic score certificate.
- **Topic 13 Spotlight — Cross-Industry Application Matrix:** Explores AI, robotics, IoT, and blockchain across Education, Healthcare, Agriculture, Manufacturing, Transportation, Banking, Retail, and Entertainment.
- **Topic 14 & 15 Spotlight — Decision Framework & Societal Implications:** Real college case study (St. Jude Tech Academy) choosing an affordable AI tutor over costly VR, plus future job shifts and green data centers.
- **Live Search & Category Filtering:** Instant keyword filtering and pill tabs (AI & Data, Hardware, XR, Blockchain, Strategy).
- **Interactive Holographic Dossier Modal:** Keyboard accessible (`Esc`, `Enter`), tabs scroller, and smooth topic-to-topic navigation (`Previous` / `Next`).
- **Dark & Light Mode:** Seamless theme switcher with `localStorage` persistence.
- **Futuristic Visual Design:** Subtle cyber-grid background, canvas-rendered floating particle network, and responsive glassmorphism.

## 🚀 How to Run the Website

### Option 1: Double-Click (Zero Setup Required)
Simply double-click `index.html` in your file explorer to open it in Chrome, Edge, Brave, or Firefox.

### Option 2: Local Node.js Server (Recommended for Live Presentations)
Open PowerShell or your terminal in this directory and run:

```bash
node server.js
```

Then visit:
```
http://localhost:8080
```
